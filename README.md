# Wisely Read PPT — PPT/PDF 逐页结构化解析

将演示文稿（PPT）或 PDF 文件逐页解析为结构化的 Word 文档，每页包含整页截图、可编辑文字整理、插图描述（以行内标记形式嵌入）。

## 适用场景

专为**复杂结构的演示文稿/幻灯片**设计，特别适合商业计划书、学术报告、行业研究、财报分析等场景。确保 AI 正确理解 PPT 每一页的完整内容，而非简单的文字提取。

## 核心优势

- **不是简单的文字提取**：脚本提取仅完成 30% 工作量，70% 靠 AI 视觉核对与逻辑重排
- **分层读图策略**：整页截图快速判断结构，高清原图逐字转录复杂信息图
- **智能图片分类**：辅助配图（logo、照片、报纸版面等）简述即可；核心信息图（图表、流程图、架构图等）逐字转录所有文字和数据
- **文本组成的图表识别**：SmartArt、形状组合等非嵌入图片元素，正确整理为结构化文字而非误加图片标记
- **支持格式**：PPT（.pptx）和 PDF

## 使用要求

### 环境依赖

- **PDF 输入**：仅需 poppler（pdftoppm）
- **PPT 输入**：需要 LibreOffice 渲染器（soffice）+ xvfb（Linux 无头环境）
- **Python 依赖**：python-pptx、pdfplumber、pymupdf、python-docx、Pillow、pytesseract（脚本自动安装）

### 模型要求

- 执行视觉核对的 AI 模型**必须支持图片识别**（多模态模型）
- 通过 `read` 工具读取本地图片文件进行视觉识别

## 工作流程与分工逻辑

采用**主代理派单 + 子代理干活 + 主代理复核**的三级流水线：

| 阶段 | 内容 | 单文件 ≤10 页 | 多文件/大文件 |
|------|------|------------|--------------|
| 阶段一 | 脚本提取文字、图片、整页截图 | 主代理 | 子代理 |
| 阶段二 | 逐页视觉校准：文字重排、图片标记、信息图逐字转录 | 主代理 | 子代理 |
| 阶段三 | 全页复核、纠错、终稿输出 | 主代理自检 | 主代理复核 |

### 分工机制

- **小文件（≤10 页）**：主代理直接完成全部三个阶段，无需子代理
- **大文件或多文件**：每个文件 spawn 一个子代理并行处理，主代理逐个复核交付

### 质量保障

- 子代理只做逐页校准，**不做复核**——复核权在主代理手里
- 主代理以"大概率有遗漏/错误"的纠错心态逐页检查
- 未完成全页复核，绝对不能交付
